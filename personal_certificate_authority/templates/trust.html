Download CA Certificate

If you're viewing this page from the same machine this app is running on, trust is usually already installed (pca init runs mkcert -install automatically). These steps are for trusting the CA on a different machine — e.g. your laptop's browser, when this app runs on a remote server.

Windows

Double-click the downloaded certificate file, choose "Local Machine", then place it in the "Trusted Root Certification Authorities" store.

macOS

Open the downloaded file in Keychain Access, add it to the "System" keychain, then double-click it, expand "Trust", and set "When using this certificate" to "Always Trust".

Linux (system-wide) 
sudo cp rootCA.pem /etc/pki/ca-trust/source/anchors/personal-ca.pem
sudo update-ca-trust extract

# Debian/Ubuntu instead:
sudo cp rootCA.pem /usr/local/share/ca-certificates/personal-ca.crt
sudo update-ca-certificates
Firefox / Chrome (Linux, NSS database) 
certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "Personal CA" -i rootCA.pem

Requires the certutil tool (package libnss3-tools on Debian/Ubuntu or nss-tools on Fedora/RHEL).

Command-line tools (curl, Python requests, Node.js) 
export SSL_CERT_FILE=/path/to/rootCA.pem
export REQUESTS_CA_BUNDLE=/path/to/rootCA.pem
export NODE_EXTRA_CA_CERTS=/path/to/rootCA.pem

Uninstalling

If you decommission a machine, or no longer want this CA trusted somewhere, reverse whichever of the steps above you did. This doesn't delete any certificates already issued by the CA — they still exist, they just stop being trusted once the CA itself is removed.

Same machine (this one) 
pca uninstall

Add --system-trust too if you'd installed that with pca init --system-trust.

Windows

Open "Manage Computer Certificates", find the CA under "Trusted Root Certification Authorities", right-click it, and choose "Delete".

macOS

Open Keychain Access, find the CA (search for its common name), right-click it, and choose "Delete".

Linux (system-wide) 
sudo rm /etc/pki/ca-trust/source/anchors/personal-ca.pem
sudo update-ca-trust extract

# Debian/Ubuntu instead:
sudo rm /usr/local/share/ca-certificates/personal-ca.crt
sudo update-ca-certificates --fresh
Firefox / Chrome (Linux, NSS database) 
certutil -d sql:$HOME/.pki/nssdb -D -n "Personal CA"
